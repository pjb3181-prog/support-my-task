# Story Director v1.2.8 — AI 자율 전개·편집자 모드 (2026-11-16)

## 배경

기존 기본 `auto`가 설정에 근거한 NPC의 감정·대사·다음 사건을 세부 지시문으로 미리 지정하고, 사용자에게 매 턴 방향 설정이나 선택을 맡기는 문제가 있었음. 사용자는 소설을 직접 조종하는 플레이어가 아니라 전체 흐름을 보며 필요할 때만 수정하는 편집자 역할을 원함.

## 변경 내용

1. 기본 `auto` 모드는 **원고 생성 AI가 스스로 전개**하도록 권한을 위임하는 1~3문장의 브리프 작성으로 전환. 현재 사건과 인물 성격, 확인된 세계관 및 사용자 지정 조건을 우선하며, 임의 갈등/발각/감정 반응 지정 금지.
2. `auto`에서는 각 NPC가 다음에 보일 감정을 선판정하지 않음. 특정 선택을 판정하고 싶을 때 `judge` 또는 `check`를 별도로 사용.
3. 스토리 디렉터 입력칸을 비워 둬도 **기존 설정·최신 채팅 기준**으로 자율 진행 요청 가능.
4. 전체 화면과 도킹 패널 모두 `AI 자율 전개안 보기` 및 `AI에게 맡겨 바로 이어가기` 버튼 제공. 빠른 진행 버튼도 **실제 전송 전 확인창**을 거치며 첫 메시지 보호 유지.
5. 결과의 `options` 선택지를 자율 모드에서 표시하지 않음. 세부 지시문 모드, 설정 상담, 세계관 수정, 복원 등 기존 기능 유지.
6. 플러그인 ID `story_director`, `PREFIX = story_director_v1:`, `//@update-url` 유지. 헤더 버전만 `1.2.8`로 증분.
