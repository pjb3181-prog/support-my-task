# Story Runner v0.95.10

기준: v0.95.9. 플러그인 ID `story_runner`, 업데이트 URL 변경 없음. 롤백 기준 태그: `plugins-pre-pr42`.

- 호출 토큰이 있는 요청과 보조 모드 요청은 건드리지 않는다.
- 스트리밍 응답도 최고 품질 재작성을 한다(출력 리스너에서 비평가·재작성 1회, 저장 직전 본문이 같을 때만 1회 저장). 일반 응답은 기존처럼 `afterRequest`.
- 상태 표식 정리를 스트리밍 응답에도 적용.
- 비평가·재작성이 4분 안에 끝나지 않으면 원문을 유지하고 "검수 예정" 표시를 해제.
- 검수 영수증(설치본 기능 유지)과 "검수 예정" 표시로 Bard Editor Lab과의 중복 퇴고를 방지.
- 저장 키는 기존과 동일. 새 키: `risubard_editorial_receipt_v1:<chatId>`.
